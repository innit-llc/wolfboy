# F4 · Visitors' browsers contact Google's tag service as soon as the page opens, before any consent choice.
- To fix · high · Google tag or Analytics loads with no consent check found
  · 37897b · review of 19 Nov 2026 · [report](../report.md)
- Place: [`public/index.html:9`][1] ·
  `<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXX…`
- Provision: ePrivacy Directive 2002/58/EC, Art. 5(3) · Directive
  2009/136/EC, Art. 2(5) [and 3 more](#provisions)
- Reason: script tag that loads Google's tag at page open; the browser's
  request carries IP and device details and nothing in the page conditions
  it on consent.
- What to do (the AI review's suggestion; check it before applying): Load
  Google tag only after a recorded consent choice.
- In general: Set Google's consent defaults to denied before any Google tag
  loads; load noscript or server tags only after consent.
