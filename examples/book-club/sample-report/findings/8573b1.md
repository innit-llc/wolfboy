<summary>The review's reasoning, in full</summary>

- What the review said: The code builds a Gravatar address from an MD5 hash
  of the member's lowercased e-mail (src/avatar\.ts:5-6).
  src/signup\.ts:18-23 returns that address to the browser, and
  public/app\.js:27 writes it into an img tag, so the visitor's browser
  requests Gravatar straight after sign-up. Gravatar therefore receives the
  e-mail hash, which is personal data, along with the visitor's IP address
  and device details. I searched the repository for an off switch or local
  avatar fallback and found none; a consent check could not be found
  either, since no consent vocabulary appears in any file the scan read.
  The product is offered in the EU, as the person declared. The file ships:
  Dockerfile:6 copies src and Dockerfile:7 copies public.
